# 3×3 폭탄 아이템 명세 (아이템 2)

근거: `docs/requirments2.md` 4.2, 4.5, 이슈 #16. 기능 브랜치: `feat/item-2-bomb`.
등장 규칙·화면 ID 등 아이템 공통 구조는 `item-structure.md`를 본다.

## 표시와 등장

- 폭탄은 **포함형** 아이템이다. 10줄 아이템 기회로 선택되면 일반 블록의 무작위 한 칸에 문자 `B`가 붙는다.
  이동·회전 중에도 `B`는 같은 칸을 따라간다.

## 효과

1. `B`가 붙은 블록이 고정되는 순간, `B` 칸을 중심으로 한 **3×3 칸을 지운다**.
   폭탄 블록 자신의 칸도 범위 안에 있으면 함께 지워진다.
2. 보드 밖으로 나가는 부분(벽, 바닥, 천장)은 잘라 낸다.
3. 지운 칸 위의 블록은 **내려오지 않는다**. 무게추와 같이 행을 압축하지 않는다.
4. 지운 칸에는 **점수가 없고**, 삭제한 줄 수에도 세지 않는다. 다음 아이템 기회 계산에도 들어가지 않는다.

## 문서에서 정하지 않은 세부 규칙

- **폭탄 블록이 완성한 줄:** 고정 순간 이미 꽉 찬 행은 폭발 범위에서 빼고, 이어지는 줄 삭제에서 지운다.
  그래서 폭탄 블록으로 줄을 완성하면 그 줄은 기존 규칙대로 삭제·점수·줄 수에 반영되고,
  폭발은 나머지 행에만 적용된다. (폭발이 먼저 칸을 지워 줄이 사라지지 않게 되는 손해를 막기 위함)
- 폭탄 블록 자신의 낙하 점수(자동·소프트·하드 드롭)는 일반 블록과 같다.

## 연결 구조

- `game.ItemType.BOMB`: 아이템 ID `4`, 문자 `B`, 포함형.
- `block.Bomb.blastCells(BoardView, Cell)`: 폭발 범위 계산. 보드 안의 3×3 좌표 중 꽉 찬 행을 뺀 목록을
  위에서 아래, 왼쪽에서 오른쪽 순서로 돌려준다. 보드는 바꾸지 않는다.
- `BlockBoardDriver.lockAndClearLines()`: 블록을 기록한 뒤 `Board.eraseCells(Bomb.blastCells(...))`로 폭발시키고,
  이어서 기존 줄 삭제를 수행한다. 엔진은 바꾸지 않는다.

## 화면 연동 (UI 담당 요청)

폭발 효과는 화면 수정 없이 동작한다. `B` 칸과 `B` 미리보기는 `item-structure.md`의 "화면 연동"이
반영되어야 화면에 그려진다.

## 검증

```powershell
.\gradlew.bat test --tests "com.team.tetris.block.BombTest" --tests "com.team.tetris.game.BombItemTest"
```

- `BombTest`: 3×3 범위와 순서, 벽·바닥·천장에서 잘림, 꽉 찬 행 제외, 위 블록이 떠 있는 채로 남음, 잘못된 중심 거부.
- `BombItemTest`: `B` 칸 표시와 고정 보고, 실제 게임 흐름에서 3×3 삭제와 압축 없음,
  폭탄 블록이 완성한 줄의 삭제·집계, 지운 칸에 점수 없음.
