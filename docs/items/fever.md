# 피버 타임 아이템 명세 (아이템 1)

근거: `docs/requirments2.md` 4.2, 4.5, 이슈 #15. 기능 브랜치: `feat/item-1-fever-time`.
등장 규칙·화면 ID 등 아이템 공통 구조는 `item-structure.md`를 본다.

## 표시와 등장

- 피버는 **포함형** 아이템이다. 10줄 아이템 기회로 선택되면 일반 블록의 무작위 한 칸에 문자 `F`가 붙는다.
  이동·회전 중에도 `F`는 같은 칸을 따라간다.
- 효과가 켜져 있는 동안 화면에 `FEVER x2`와 남은 초를 표시한다(화면 연동 참고).

## 효과

1. `F`가 붙은 블록이 고정되는 순간 피버가 시작된다. `F` 자체는 줄을 지우지 않는다.
2. 피버는 **10초** 동안 유지되며, 그동안 얻는 **모든 점수가 2배**가 된다.
   (자동 낙하, 소프트 드롭, 하드 드롭, 줄 삭제 점수 모두 포함)
3. `F` 블록 자신의 낙하·줄 삭제 점수는 고정 전에 계산되므로 2배가 되지 않는다.
4. 피버 중에 `F`를 또 고정하면 남은 시간을 더하지 않고 **10초로 다시 채운다**.

## 문서에서 정하지 않은 세부 규칙

- **일시정지:** 일시정지·재개 사이의 시간은 피버 시간에서 빠지지 않는다.
  재개하면 남은 초부터 다시 1초씩 줄어든다.
- **게임 종료·새 게임:** 게임을 끝내거나 새로 시작하면 피버도 끝난다.

## 연결 구조

- `game.ItemType.FEVER`: 아이템 ID `3`, 문자 `F`, 포함형.
- `GameEngine`: 블록 고정 후 `board.lockedItem()`이 `FEVER`이면 피버를 켠다. 피버 전용 1초 타이머
  (`DropTimer`)로 남은 시간을 줄이고, `award()`에서 점수를 2배로 만든다. 일시정지·종료 시 다른 타이머와
  함께 멈춘다. `GameEngine.FEVER_SECONDS`, `FEVER_MULTIPLIER`, `getFeverSeconds()`를 공개한다.
- `GameEventListener.onFeverChanged(int)`: 남은 초가 바뀔 때 화면에 알린다. 0이면 피버 종료.
  기본 메서드라 기존 리스너는 바꾸지 않아도 된다.

## 화면 연동 (UI 담당 요청)

점수 2배 효과는 화면 수정 없이 동작한다. 아래가 반영되기 전까지 `F` 칸과 `F` 미리보기는 화면에 그려지지 않는다.

1. 포함형 아이템 칸 그리기: `item-structure.md`의 "화면 연동"을 따른다.
2. `GameScreen`의 리스너에서 `onFeverChanged`를 받아 남은 초를 표시한다(0이면 숨김).
3. `Main.ForwardingListener`에 `onFeverChanged` 전달을 추가한다.

재획득 시 10초로 갱신, 새 게임 시 종료를 확인한다.
