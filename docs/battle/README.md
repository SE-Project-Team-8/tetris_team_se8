# 로컬 2인 대전 모드 문서

근거: `docs/requirments3.md` p.2~7(대전 모드), 팀 문서 「3차 요구사항 · 역할 배정」(2026-11-16). 담당: 윤성빈. 마감: 11/25, P2P와 통합 11/27.

> **상태: 구현 전 설계 초안.** 이 폴더의 클래스·메서드 이름은 계획이며 아직 코드에 없다.
> "제안"으로 표시한 규칙은 팀 확인 전이다. 구현하면서 달라진 내용은 해당 문서를 같이 고친다.

## 범위

- **포함**: 시작 메뉴의 대전 모드 항목, 게임 방식 선택(일반/아이템/시간제한), 엔진 2개 동시 구동, 공격과 공격 대기열,
  2인 키 입력, 대전 화면, 승패 판정과 승자 화면, 대전 로직 단위 테스트.
- **제외**: P2P 대전(손동민), 뿌요풍 비주얼·공격 연출(조상윤·안성현, `docs/design/design-spec.md` §3.2), 도전 과제.
- 다른 담당과 맞닿는 부분은 `integration.md`에 모았다.

로직(1~4)을 먼저 끝내 PR 하나, 화면(5~7)을 PR 하나로 올린다. 1~4는 화면 없이 테스트할 수 있고 P2P가 그대로 가져다 쓴다.

| # | 작업 | 산출물 | 관련 요구사항 |
| --- | --- | --- | --- |
| 1 | 공격 줄과 대기열 | `GarbageLine`, `GarbageQueue` + 테스트 | LB-F09~F12 |
| 2 | 보드·드라이버 | 회색 줄 저장·삽입, 공격 줄 모양 계산 | LB-F05, F07, F08 |
| 3 | 엔진 연결 지점 | 고정 후 공격 전달, 생성 전 대기열 삽입 | LB-F04, F07 |
| 4 | 대전 진행 관리 | `VersusMatch`: 엔진 2개, 승패, 시간제한 | LB-F03, F13, F16, F17 |
| 5 | 2인 입력 | 창 전체 키 분배와 자체 반복 | LB-F18, LB-I01 |
| 6 | 화면 | 메뉴 항목, 방식 선택, 대전 화면, 승자 화면, 일시정지 | LB-F01, F02, F06, F14 |
| 7 | 마무리 | 아이템·시간제한 확인, 창 크기 3단계, 수동 점검 | LB-F16, F17, LB-I05 |
