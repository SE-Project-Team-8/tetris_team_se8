# 참고 게임 규칙: 뿌요뿌요 테트리스 (테트리스 대 테트리스)

로컬 대전의 규칙을 정할 때 참고하는 기존 게임의 대전 규칙을 적는다. 대상은 「뿌요뿌요 테트리스」의 **테트리스 대 테트리스(TvT) 대전**이다.

- 가져오는 것은 **규칙(게임 로직)** 뿐이다. 이름·캐릭터·그림·소리·화면 구성은 가져오지 않는다.
- **과제 요구사항(`docs/requirments3.md`)이 항상 우선한다.** 요구사항과 어긋나는 규칙은 참고만 하고 따르지 않는다(2절).
- 조사일 2026-11-23. 공식 규칙서가 아니라 커뮤니티 위키의 정리와 분석을 옮긴 것이다. 출처마다 확인 수준을 표시했다.

## 1. 참고 게임의 규칙

확인 수준: **확인** = 해당 게임의 TvT에 대해 출처가 직접 적음 / **일반** = 같은 계열(가이드라인) 대전 테트리스의 일반 규칙으로만 확인 / **미확인** = 출처에서 찾지 못함.

### 1.1 공격량

지운 줄 자체가 넘어가는 것이 아니라, 지운 방식에 따라 정해진 **줄 수**만 넘어간다. [S2, S4]

| 지운 방식 | 보내는 줄 수 | 확인 수준 |
| --- | --- | --- |
| 1줄 | 0 | 확인 |
| 2줄 | 1 | 확인 |
| 3줄 | 2 | 확인 |
| 4줄 | 4 | 확인 |
| T스핀 1줄 / 2줄 / 3줄 | 2 / 4 / 6 | 확인 |
| 미니 T스핀 | 지운 줄 수와 같게 (추가 없음) | 확인 |
| 연속 4줄·T스핀 (back-to-back) | +1 | 확인 |
| 보드를 모두 비움 (perfect clear) | 항상 10 | 확인 |

- 연속으로 줄을 지우면(콤보) 추가로 보낸다. 콤보 1회째 0, 2~3회째 +1, 4~5회째 +2, 6~7회째 +3, 8~10회째 +4, 11회째부터 +5. [S2, S4 — 표의 행 제목이 깨져 있어 순서로 읽은 값]
- 1줄 삭제는 콤보 중이거나 보드를 모두 비웠을 때만 줄을 보낸다. [S2]

### 1.2 상쇄

- **상쇄가 있다.** 받을 줄이 대기 중일 때 줄을 지우면, 보낼 줄 수만큼 대기 중인 줄을 먼저 없애고 **남은 것만** 상대에게 보낸다. [S2] — 확인
  - 원문: "there's garbage countering (incoming garbage lines are cancelled before garbage is sent over to the opponent)".
- **막기는 없다.** 줄을 지운 차례에도 대기 중인 줄은 들어온다(콤보 중에도 들어온다). [S2] — 확인
  - 원문: "There's no garbage blocking (thus garbage may be inserted during a combo)."

### 1.3 받은 줄이 보드에 들어가는 시점과 양

- 블럭을 놓았을 때 보드 아래로 들어온다. 줄을 지운 차례에도 들어온다(1.2). TvT에서의 정확한 지연 시간은 미확인.
- 한 번에 들어오는 양의 상한: 테트리스 쪽은 한 번에 최대 7줄이라는 서술이 있으나 [S6, 검색 요약으로만 확인], TvT에 대해 직접 적은 출처는 찾지 못했다. — 미확인
- 대기 중인 줄의 총량 상한: TvT에 대해서는 미확인.

### 1.4 받은 줄의 모양

- 요구사항과 달리, 넘어온 줄은 보낸 사람의 블럭 모양과 무관하다. 줄마다 **구멍이 있는** 줄이다. [S2] — 확인("the garbage hole")
- 한 번에 여러 줄이 들어오면 이웃한 두 줄의 구멍이 같은 열일 확률이 약 70%다. 새로 들어온 맨 아래 줄의 구멍이 이전에 받은 줄과 같은 열일 확률은 약 10%다. [S2] — 확인
- 색: 해당 게임에 대해서는 미확인. 같은 계열 게임은 보통 회색이다. [S3] — 일반
- 받은 줄을 채워 지웠을 때의 취급(점수·공격): 출처에서 직접 확인하지 못했다. 같은 계열 게임에서는 일반 줄과 구분하지 않는 것으로 알려져 있다. — 미확인

### 1.5 테트리스 쪽 기본 규칙

| 항목 | 내용 | 확인 수준 |
| --- | --- | --- |
| 보드 | 가로 10 × 세로 20 (보이는 영역) | 확인 [S2, S4] |
| 다음 블럭 미리보기 | 5개 (3~4인 대전은 3개) | 확인 [S2, S4] |
| 회전 방식 | SRS (벽 보정 포함) | 확인 [S2, S4] |
| 보관(hold), 하드드롭 | 있음 | 출처 간 불일치 (S4 있음, S2 표는 "N/A") |
| 블럭 순서 정하는 방식, 고정 지연, 낙하 예고, 패배 조건의 세부 | — | 미확인 |

- 대전의 테트리스 쪽은 "요즘 대전 테트리스 게임과 다르지 않다"고 적혀 있다. [S2]
- **시간에 따른 공격 강화는 TvT에 없다.** 시간이 지나면 공격이 세지는 규칙(마진 타임)은 뿌요 쪽이 섞인 대전에만 적용된다. [S2, S4] — 확인

## 2. 과제 요구사항과의 대조

"적용"이 **불가**인 항목은 요구사항이 다른 규칙을 정해 놓아 참고 게임을 따를 수 없다.

| # | 참고 게임 | 과제 요구사항 | 적용 | 현재 문서 |
| --- | --- | --- | --- | --- |
| R1 | 공격량은 표로 정한 줄 수 (2줄 삭제 → 1줄) | 2줄 이상 삭제하면 **삭제된 줄들이** 넘어간다 (p.4) | **불가** | `rules.md` 2.1 |
| R2 | 넘어온 줄은 구멍 하나짜리 줄, 구멍 열은 확률로 결정 | 삭제된 줄에서 마지막 블럭 칸을 뺀 **형태 그대로** (p.4, p.5) | **불가** | `rules.md` 2.2 |
| R3 | T스핀·콤보·연속·전체 비움에 추가 공격 | 넘어가는 것은 삭제된 줄뿐 | **불가** (공격량으로는). 점수 보너스로만 넣을 수 있으나 범위 밖 | — |
| R4 | 상쇄 있음: 대기 중인 줄을 먼저 없애고 남은 것만 보냄 | 언급 없음 (p.5 "자유롭게 결정") | **불가** — p.4가 "삭제된 줄들이 넘어간다"고 조건 없이 적어, 상쇄하면 넘어가지 않는 줄이 생긴다 (D-08) | `rules.md` 2.2, `decisions.md` D-04·D-08 |
| R5 | 막기 없음: 줄을 지운 차례에도 받은 줄이 들어옴 | 블럭 처리 후, 다음 블럭 생성 전에 추가 (p.4) | **일치** | `rules.md` 4절 |

| R7 | 받은 줄을 지우면 일반 줄과 같게 취급 (미확인) | 언급 없음 | **일치** (같은 계열 게임의 일반 동작 기준. D-09) | `rules.md` 2.2 |

| R9 | 시간에 따른 공격 강화 없음 (TvT) | 시간제한 방식은 별도 규칙 (p.3) | 해당 없음 | `rules.md` 6절 |

## 3. 정리

- 참고 게임 대전의 핵심인 **공격량(R1)과 받은 줄의 모양(R2)은 요구사항이 다르게 정해 놓아 따를 수 없다.** 이 과제의 대전은 "지운 줄이 모양 그대로 넘어가는" 고유한 방식이다.
- 이미 같은 것: 막기 없음(R5), 회색(R8), 패배 조건(R12).
- 상쇄(R4)는 참고 게임에 있지만 넣지 않는다. 지운 줄이 넘어간다는 요구사항 문장과 어긋나기 때문이다(`decisions.md` D-08).
- 받은 줄을 지웠을 때의 취급(R7)은 일반 줄과 같게 정했다(`decisions.md` D-09).
- 조작감에 해당하는 것(R11)은 대전 규칙이 아니라 게임 전체의 변경이라 이번 범위에서 다루지 않는다.
